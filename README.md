# Marvel Info

A static Marvel character and comics lookup app built with HTML, CSS, and JavaScript.

## Features

- Search Marvel characters by name
- Display character images and Superhero API IDs
- Search Marvel comic issues by title
- Search a character's comic issues by Superhero API character ID
- Display Comic Vine issue IDs, covers, issue numbers, and series names
- Search comic descriptions by Comic Vine issue ID or title
- Marvel-only filtering for character and comic results
- Local fallback images and demo content when an API request fails

## Run Locally

Open the project in VS Code and use **Open with Live Preview** on `index.html`.

You can also open `index.html` directly in a browser, but Live Preview is recommended for API requests.

## API Services

The app uses:

- Superhero API for character data and images
- Comic Vine API for comic issues, covers, and descriptions

## Project Files

- `index.html` - Page structure and search controls
- `scrpit.js` - API requests, filtering, rendering, and interactions
- `style.css` - Main layout and responsive styling
- `stylesheet.css` - Marvel font definition
